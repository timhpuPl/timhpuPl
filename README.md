## 🦀 Featured Project — Wipekit

> A free, self-hosted web panel for managing Rust dedicated servers.
> Control, monitor, manage players, and automate tasks — all from one modern interface.

| | |
|---|---|
| 🖥️ Real-time RCON console | WebSocket streaming, command input, clean mode |
| 📊 Live metrics | CPU, memory & uptime updated every 5 seconds |
| 👥 Player management | Playtime tracking, VAC bans, kick / ban / mute |
| 📅 Smart scheduler | Map wipes, restarts, broadcasts on cron schedules |
| 📁 File manager | Browse & edit server files without SSH |
| 🧩 Oxide / Carbon | Plugin management built-in |
